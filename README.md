## 🎮 Tic-Tac-Toe (x86 Assembly)
A simple Tic-Tac-Toe game built in x86 Assembly using the FASM assembler and IDE.
Includes both the source .asm file and a compiled .exe executable, allowing the game to be played directly in a terminal environment.
The program handles user input, validates moves, and updates the game board entirely through low-level assembly logic.
